# The Student Dev Hub

A curated hub of 45+ free tools for tech students: learning, coding, practice, deployment, design and careers. Built with plain HTML, CSS and JavaScript, in a single file.

**Live site:** https://YOUR-USERNAME.github.io/student-dev-hub/

![Student Dev Hub screenshot](screenshot.png)

## Features

- **45+ curated tools** across 8 categories: Learn, Code, Practice, Data & AI, Deploy, Design, Productivity and Career
- **Instant search** by tool name, keyword or category
- **Category filters** to browse one area at a time
- **Favourites** saved in your browser, so your daily tools are one click away
- **Focus timer** with 25-minute study sessions and 5-minute breaks
- **Study habits** panel with practical tips
- **Responsive design** that works on phones, tablets and desktops
- **Light and dark mode** that follows your device setting
- **Accessible** with keyboard navigation and visible focus states

## Run it locally

No installation or build step is needed.

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR-USERNAME/student-dev-hub.git
   ```
2. Open `index.html` in your browser.

## Add a tool

Open `index.html` and find the `T` array in the script section. Add a new line in this format:

```js
["Category", "Tool name", "One-line description.", "https://example.com"],
```

Use an existing category name so the tool appears in the right section.
